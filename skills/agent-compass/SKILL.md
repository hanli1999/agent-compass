# Agent Compass

Use the generic CLI or Python API when an agent needs to:

1. decide whether local context is enough;
2. decide whether a question needs clarification;
3. pause before an external side effect;
4. checkpoint and resume a multi-step task;
5. inspect or redact text before remote transfer;
6. propose a small, factual, privacy-classified memory.

The host agent remains responsible for tool execution. Never put credentials or private memory into this skill file.
